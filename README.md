# overview

this is an unofficial web port, i am not affiliated with infinity ward or activision in anyway (ill take an internship tho :eyes:)  
right now you can only play the campaign (main story + mile high club), multiplayer will come soon

# how can i play this?
you will need a copy of the original cod 4 game, this port does NOT enable piracy on its own.

### option 1: go to mw.slqnt.dev  
once there upload your game files, select what you want to install, and wait for it to copy, then press play and enjoy.

### option 2: hosting yourself  
clone this repo and set up a server that sends coop/coep headers for threading.
